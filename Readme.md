# 林欣妍 (Hsin-Yan Lin) 個人網頁

這是一個為林欣妍量身打造的單頁式（Single-Page）個人作品集與簡歷網頁。網頁採用乾淨、現代的淺色主題設計，能清楚展示個人資訊、興趣、專業技能以及聯絡方式，並具備完整的響應式設計（RWD），在手機、平板與電腦上皆有良好的瀏覽體驗。

## ✨ 網頁特色

*   **單一檔案結構**：所有的 HTML、CSS（透過 Tailwind CSS）與 JavaScript 皆整合在單一個 `.html` 檔案中，無需繁雜的檔案配置，方便分享與部署。
*   **現代淺色主題**：使用柔和的背景漸層、充足的留白與細緻的陰影，呈現專業且舒服的視覺感受。
*   **響應式設計 (Responsive Web Design)**：版面會根據使用者的裝置螢幕大小自動調整，確保最佳的閱讀體驗。
*   **微互動設計**：包含導覽列的平滑滾動（Scroll Smooth）、卡片懸浮效果（Hover effects），以及實用的「點擊複製 Line ID」提示功能。

## 🛠️ 使用技術

本專案使用以下開源工具與前端技術（皆透過 CDN 引入，無需安裝任何套件）：

*   **HTML5**: 負責網頁的語意化結構。
*   **[Tailwind CSS](https://tailwindcss.com/) (透過 CDN)**: 快速且高度客製化的實用優先 CSS 框架，用於處理網頁的排版與樣式。
*   **Vanilla JavaScript**: 處理簡單的頁面互動邏輯（如：點擊複製剪貼簿功能與提示訊息）。
*   **[Font Awesome](https://fontawesome.com/)**: 提供網頁中使用的向量圖示（Icons）。
*   **[Google Fonts (Noto Sans TC)](https://fonts.google.com/specimen/Noto+Sans+TC)**: 採用思源黑體，確保繁體中文字體的優美與易讀性。

## 🚀 如何使用與預覽

因為這是一個純前端的靜態網頁，預覽方式非常簡單：

1.  將生成的 HTML 程式碼儲存為一個檔案，例如：`portfolio.html` (或 `index.html`)。
2.  對該檔案點擊「右鍵」，選擇「使用瀏覽器開啟」（例如 Google Chrome, Safari, Edge 等）。
3.  您即可在瀏覽器中看到完整的網頁呈現效果。

**注意事項：**
由於使用了 Tailwind CSS 的 CDN 版本來即時編譯樣式，請確保您的裝置在開啟網頁時**已連上網路**，才能正確載入樣式、字體與圖示。
